## 学习重点

1. MVC → MVP → MVVM → MVI 的演进逻辑和各自优缺点
2. ViewModel 如何在配置变更时保留数据（onRetainNonConfigurationInstance）
3. LiveData 粘性事件问题 + 解决方案
4. ARouter 路由原理（APT 编译时生成路由表）
5. Compose 声明式 UI + Recomposition 机制

## 串联思考

- MVVM → ViewModel + LiveData/Flow（Day 3 协程和 Flow）
- MVI → Compose + 单向数据流（当前最推荐组合）
- 组件化 → ARouter 用 APT 注解处理器（Day 2 反射/注解）
- Jetpack 组件 → Lifecycle 感知（Activity/Fragment 生命周期，Day 4）
