## 学习重点

1. View 三大流程：measure → layout → draw
2. 事件分发三个方法：dispatch → intercept → onTouchEvent
3. RecyclerView 四级缓存 + DiffUtil + 预取机制

## 串联思考

- View 绘制 → RecyclerView 的 LayoutManager 就是在做 measure + layout
- 事件分发 → RecyclerView 滚动基于 onTouchEvent + 嵌套滑动
- measure 过程 → 性能优化：减少层级 = 减少递归深度（Day 8 渲染优化）
