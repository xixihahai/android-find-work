## 学习重点

1. synchronized 锁升级：偏向锁→轻量级锁→重量级锁
2. volatile 的两个语义：可见性 + 禁止重排序
3. 双亲委派模型 + Android 的 PathClassLoader / DexClassLoader
4. 类型擦除的影响 + TypeToken 如何保留泛型信息

## 串联思考

- AQS → ReentrantLock / CountDownLatch / Semaphore（Day 6 并发工具）
- 类加载机制 → 热修复（Day 11 插件化）
