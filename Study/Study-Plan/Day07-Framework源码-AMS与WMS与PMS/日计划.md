## 学习重点

1. 系统启动链路：BootROM → Bootloader → Kernel → init → Zygote → SystemServer → Launcher
2. Zygote 的预加载 + fork 机制（为什么 App 启动快）
3. AMS 管 Activity 生命周期和进程优先级
4. WMS 管窗口层级和 Surface
5. PMS 管 APK 安装和权限

## 串联思考

- Zygote fork → App 进程启动（启动优化的起点）
- AMS → Activity 启动流程（Day 4 的源码解释）
- WMS → Window Token → 为什么 Dialog 需要 Activity Context
- PMS → APK 安装 → dex2oat 优化（启动优化相关）
