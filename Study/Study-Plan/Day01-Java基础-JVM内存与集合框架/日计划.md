## 学习重点

1. JVM 五大内存区域各自存什么、会不会 OOM
2. GC 算法的演进逻辑（标记清除→标记整理→分代收集）
3. HashMap 的核心设计：数组+链表+红黑树，扩容机制
4. ConcurrentHashMap 的分段锁→CAS+synchronized 演进

## 串联思考

- JVM 堆 → Android 的 Heap 限制 → OOM（Day 8 会深入）
- 四种引用 → Glide 的缓存策略（Day 10 会用到）
- HashMap → LruCache → RecyclerView 的 Pool（Day 5 会串联）
