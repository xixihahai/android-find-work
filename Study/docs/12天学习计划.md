# Android 高级面试 12 天学习计划

> **目标**：12 天系统掌握 Android 高级面试核心知识，能灵活运用而非死记硬背。
> **方法论**：每天"学 → 串 → 练 → 验"四步法。
> **时间安排**：建议每天 3-4 小时（2h 学习 + 1h 练习 + 0.5h 复习回顾）

---

## 学习方法说明

### 每日四步法

```
┌─────────────────────────────────────────────────────────┐
│  第一步：学（60min）                                     │
│  阅读当天指定文档，重点看"速记总结"和"核心原理"          │
│  目标：建立知识框架，理解"为什么"                        │
├─────────────────────────────────────────────────────────┤
│  第二步：串（30min）                                     │
│  看文档中的"知识串联"部分，回忆关联知识                  │
│  目标：把孤立知识点连成网                                │
├─────────────────────────────────────────────────────────┤
│  第三步：练（60min）                                     │
│  完成当天作业：口述题 + 场景分析题 + 代码题               │
│  目标：验证理解深度，暴露薄弱点                          │
├─────────────────────────────────────────────────────────┤
│  第四步：验（30min）                                     │
│  "费曼学习法"——用自己的话给一个不懂的人讲清楚            │
│  讲不清楚的地方就是没真正理解的地方                      │
│  目标：从"我知道"到"我能讲"                             │
└─────────────────────────────────────────────────────────┘
```

### 作业评判标准

每道作业题用以下标准自我评估：
- **A（能当面试官）**：不看笔记，能清晰讲出原理+场景+代码，还能提出追问
- **B（能通过面试）**：看一眼速记表就能完整回答，有遗漏但核心到位
- **C（需要加强）**：需要反复看文档才能回答，说明理解不够深
- **D（完全不会）**：标记为重点复习对象，第 11-12 天集中攻克

2. 设计题的回答框架（需求分析→架构→核心实现→扩展性）
3. 场景题的回答框架（定义问题→排查工具→根因→方案→量化）

### 每日作业（模拟面试，限时回答）

**项目经验（每题 3 分钟口述）**：
1. 描述你做过的最有技术挑战的项目，用 STAR 法则
2. 你在项目中做过哪些性能优化？用数据量化结果

**设计题（每题 10 分钟，画架构图+说核心实现）**：
3. 设计一个图片加载框架，要求支持三级缓存、生命周期感知、大图加载
4. 设计一个 App 的日志系统，要求支持实时上报和本地存储

**场景题（每题 5 分钟）**：
5. 线上用户反馈某个列表页滑动卡顿（45fps），你的排查和优化流程
6. 线上出现大量 ANR（Service 超时），如何定位和解决？
7. App 从 Android 13 升级到 Android 14 后，部分功能异常，排查思路？

**终极测试**：
8. 闭卷（不看任何文档），在纸上画出以下内容：
   - Android 系统启动流程（从开机到 Launcher）
   - RecyclerView 四级缓存全景图
   - Activity 启动流程（跨进程调用链）
   - Handler 消息机制流程图
